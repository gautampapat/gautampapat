### Main Projects

#### [Zenis](https://github.com/gautampapat/Zenis): Low-Token AI Presentation Engine
Automated presentation generator with deep web research. Offloads 90% of processing from LLMs to scrapers (Trafilatura, PyMuPDF) and lightweight decision models. Uses a two-pass slide reducer and micro-synthesis to hit <$0.005 cost per deck with sub-8s generation.
- **Stack:** Python, Trafilatura, PyMuPDF, Chonkie, BAML, python-pptx, React

#### [eduWin](https://github.com/gautampapat/eduWin): Coaching Institute Operations Platform
Multi-tenant management system for tuition centers covering batch scheduling, attendance, and fee tracking. Uses Postgres Row-Level Security for strict tenant isolation and rotating JWT refresh tokens.
- **Stack:** Python 3.13, FastAPI, SQLAlchemy, PostgreSQL 16 (RLS), Redis, Docker, React 19, Tailwind CSS

#### [Parakh](https://github.com/gautampapat/parakh): Product Label & Safety Scanner
Mobile and web app that evaluates food, beverage, and cosmetic labels against statutory FSSAI and ICMR-NIN limits using barcode scans, photos, or quick-commerce links.
- **Stack:** FastAPI, PostgreSQL + pgvector, Redis, Gemini 2.0 Flash, React 18, TypeScript, Capacitor, ML Kit
